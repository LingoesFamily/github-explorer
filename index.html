🚀 快速开始

  • 顶部两个标签页可切换 用户搜索 与 项目关键词搜索。
  • 在输入框输入关键词后按 Enter 或点击右侧按钮即可搜索。
  • 搜索结果卡片可直接点击仓库名/用户主页跳转 GitHub。

🔍 搜索技巧

  • 用户搜索：输入精确的 GitHub 用户名（区分大小写），如 torvalds。
  • 项目搜索：支持多关键词，如 react admin、machine learning python。
  • 项目默认按 ⭐ stars 降序排列，最多展示 20 个结果。
用户名示例 torvalds gaearon yyx990803 tj sindresorhus

💾 导出 CSV

  • 搜索结果出现后，标题栏右侧会出现 「导出 CSV」 按钮。
  • 导出的是当前显示的列表（用户搜索页：该用户热门仓库；项目搜索页：当前关键词结果）。
  • 文件名包含关键词与导出时间，例如 github-repos-react-20260617-1530.csv。
  • CSV 使用 UTF-8 编码（含 BOM），可直接用 Excel / WPS / Google Sheets 打开，中文不乱码。

⚠️ 关于 API 限流

  • 本应用使用 GitHub Public API，无需登录、无需 Token。
  • 未认证状态下：每 IP 每小时最多 60 次请求（搜索接口另计 10 次/分钟）。
  • 若提示「API 请求受限」，请等待几分钟后重试。

🔒 隐私说明

  • 本应用无后端服务器，所有请求由你的浏览器直接发送到 GitHub。
  • 不收集、不存储任何用户数据；导出的 CSV 仅保存到你本地。
  • 适合部署到 GitHub Pages、html2web.com、Netlify、Vercel 等任意静态托管平台。
